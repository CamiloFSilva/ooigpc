## MATLAB reproduction code

The `Archive/` folder contains the original MATLAB scripts that produced all
paper figures.  It is a self-contained reproduction package independent of the
Python implementation above.

```
Archive/
├── Examples/            PC algebraic operations tutorial (Supplementary Material)
├── Langevin_Equation/   Validation on the stochastic Langevin amplitude SDE
├── VanderPol_Equation/  Validation on the stochastic Van der Pol oscillator
└── Experiments/         Application to Noiray & Denisov (2017) experimental data
```

Each subfolder contains `igPC/`, `KMCoeff/`, `Plotting/` and a README.
See `Archive/README.md` for the complete paper figure index and workflow.
